Solmarina is a sun-soaked open-world crime game in the browser: steal cars, run six story jobs, outrun the Solmarina PD through a living city of traffic, pedestrians, beaches and docks. No build step, no network — just static files.

## Play it

```sh
node serve.ts
# open http://localhost:8080
```

WASD move / drive · E enter or steal a car · Mouse aim, click to shoot · R reload · M mute · P pause. Progress saves automatically.
